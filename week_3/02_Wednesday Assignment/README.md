Structure, styling and layout affect each other because they are all intertwined.  The HTML document has to have the elements that occur in the CSS template.  If they don't exist in the HTML document, they can't have style elements defined in the CSS sheeet.  Also, the layout of the document is done in the HTML and then those elements can be done in the CSS using the width, padding, margin, display, etc.  All has to be defined in the HTML document to be able to reference in the CSS style sheet.
