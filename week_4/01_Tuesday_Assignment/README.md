# README.md
Purpose:
The purpose of this site is to eventually use it as a resouce hub to keep everything in one place.  This site will also be used to give information to employee as well as helpful links.

Code Explanation: 
I added a java script file and had it run to check the overtime hours for an employee and then calculate the gross pay. 
If the hours are over 40, then it will print overtime hours worked and if the hours worked is under it will print no overtime worked. 
I also added a funtion to take the hourly rate times the hours worked to get a gross pay. 
The ending result is to print whether there was OT worked, # of hours worked and then the Gross Pay.
